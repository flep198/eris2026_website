NGC 660: HI Absorption Imaging

Data

In this tutorial we will image absorption from the central region of the nearby starburst galaxy NGC 660 at z = 0.002842.

The data were obtained using the European VLBI Network (EVN). We shall use the self-calibrated dataset for this tutorial since you have already learnt continuum imaging and self-calibration in the previous tutorials.

One important point to remember when imaging continuum emission from spectral-line datasets is that strong line channels should be excluded from the continuum model. If the spectral line is clearly visible in a standard plotms inspection, those channels should not be included when constructing the continuum image.

Absorption Lines

Unlike TW Hya, this dataset contains a spectral line seen in absorption rather than emission.

For an absorption line to be observed, a bright background continuum source must be present. The foreground gas absorbs a fraction of the background continuum emission at frequencies corresponding to the spectral transition.

In extragalactic radio astronomy the continuum source is often associated with AGN activity in the central regions of galaxies. In the case of NGC 660, the compact radio source is particularly interesting because it appeared only after 2008, suggesting the recent onset of nuclear activity.

The EVN observations used in this tutorial were reported by Argo et al. (2015), who used HI absorption to study the gas surrounding this newly active radio source.

HI 21-cm Line

Neutral atomic hydrogen (HI) is the most abundant element in galaxies and serves as one of the most important tracers of the interstellar medium. The HI 21-cm line is produced when the spins of the proton and electron flip from a parallel to an anti-parallel configuration.

The rest frequency of the HI line is 1420.405751 MHz. HI observations have been used to map gas distributions in galaxies, measure galaxy rotation curves and study galaxy interactions.

For NGC 660, the HI absorption arises against a compact radio source at the galaxy centre. By imaging the absorption as a function of velocity, we can investigate the structure and dynamics of the neutral atomic gas in the nuclear region.

Determine the Channels Containing the Line Feature

Before producing a spectral cube we must determine which channels contain the absorption line and identify line-free channels that can be used to fit and subtract the continuum. 

# In CASA

	plotms(
	    vis='ngc660.ms',
	    xaxis='channel',
	    yaxis='amp',
	    avgspw=False,
	    avgtime='1e9',
	    avgscan=True,
	    avgbaseline=True,
	    scalar=True,
	    showgui=True,
	)

The spectral line appears as a dip with respect to the continuum level. Notice that the line spans roughly 50 channels and that the edge channels show non-linear behaviour. 

# In CASA

	linefree='0:250~450;550~700'

These line-free channels will be used for continuum subtraction.

Continuum Subtraction

To study the absorption line, we first subtract the continuum emission from the data. In this case we use a first-order polynomial (fitorder=1) to account for the continuum slope. 

# In CASA

	os.system('rm -rf ngc660.contsub*')

	uvcontsub(
	    vis='ngc660.ms',
	    outputvis='ngc660.contsub.ms',
	    datacolumn='data',
	    fitspec=linefree,
	    fitorder=1,
	    writemodel=False,
	)
	
# In CASA

	plotms(
	    vis='ngc660.contsub.ms',
	    xaxis='channel',
	    yaxis='real',
	    avgspw=False,
	    avgtime='1e9',
	    avgscan=True,
	    avgbaseline=True,
	    showgui=True,
	    scalar=False,
	    spw='0:250~700',
	)

After continuum subtraction, the line appears as a negative feature. Plotting the amplitude would remove the sign information and make the absorption resemble emission.

Parameters Related to Velocity and Reference Frames

Rest Frequency

For extragalactic sources we use the redshifted HI frequency rather than the laboratory frequency. 

# In CASA

	rstfrq='1416.380396911976MHz'

Velocity Reference Frame

We adopt the barycentric reference frame because NGC 660 is an extragalactic source and we wish to remove the effect of the Earth's orbital motion around the Sun. 

outframe='BARY'

Velocity Type: Optical

Systemic velocities for galaxies are conventionally quoted using the optical velocity convention. Throughout this tutorial, velocities should be interpreted as optical velocities in the barycentric reference frame.

Creating a Dirty Cube

The absorption line spans roughly 50 channels. To reduce computation time we average neighbouring channels and image only the useful channel range.

The restoring beam should match the continuum image since absorption is always measured with respect to the background continuum emission. 

# In CASA

	imhead(
	    imagename='ngc660.cont.image'
	)
	
# In CASA

	beam=['0.0285065arcsec',
	      '0.0159238arcsec',
	      '-25.9153deg']

Linux

tclean(
	    vis='ngc660.contsub.ms',
	    imagename='ngc660.dirty.cube',
	    spw='0',
	    specmode='cube',
	    perchanweightdensity=True,
	    nchan=225,
	    start=250,
	    width=2,
	    outframe='BARY',
	    restfreq=rstfrq,
	    veltype='optical',
	    deconvolver='hogbom',
	    gridder='standard',
	    imsize=[320,320],
	    cell='0.0018arcsec',
	    weighting='briggsbwtaper',
	    robust=0.5,
	    restoringbeam=beam,
	    interactive=False,
	    niter=0,
	    pbcor=True
	)

Mask Creation

Load the continuum image into CARTA and create a region encompassing the outermost continuum contour. Since absorption is only observed against the continuum source, this region can be used as the CLEAN mask.

Moment Maps

Generate moment maps using the CARTA Moment Generator tool. First determine the absorption velocity range and the threshold to be applied.

See the CARTA documentation for further details on moment-map generation.

Position-Velocity Diagrams

Position-Velocity (PV) diagrams are powerful tools for investigating gas kinematics when the source is spatially resolved.

Create a line region through the source and generate a PV diagram using the CARTA PV tool.

Note that CARTA may label the velocity axis as "Radio" even when the cube was generated using the optical velocity convention. This is a display issue only and does not affect the underlying velocity values.

Exporting the Results

Export the continuum image, spectral cube, moment maps and PV diagrams as FITS files for further analysis. 

# In CASA

exportfits(
    imagename='ngc660.cont.image',
    fitsimage='ngc660_cont.fits',
    overwrite=True,
)

# In CASA

exportfits(
    imagename='ngc660.final.cube.image.pbcor',
    fitsimage='ngc660_cube.fits',
    velocity=True,
    overwrite=True,
)

Similarly export any moment maps and PV diagrams that you wish to use for further analysis.
